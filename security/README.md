# Security, Identity & Compliance

Identity, encryption, secrets, and threat detection on AWS — enforcing least
privilege and building defense-in-depth.

## Topics

- IAM (policies, roles, permission boundaries, SCPs, identity federation)
- KMS (key types, key policies, envelope encryption, grants)
- Secrets Manager & Parameter Store (rotation, cross-account access)
- Threat detection (GuardDuty findings, Security Hub, Detective)
- Least-privilege design and account isolation patterns
