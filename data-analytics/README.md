# Data & Analytics

Ingesting, cataloging, processing, and querying data at scale on AWS — from
streaming pipelines to data lakes and warehouses.

**Services covered:** Glue · Athena · Kinesis · EMR · Lake Formation

## Topics

- Glue (crawlers, Data Catalog, ETL jobs, schema evolution)
- Athena (serverless SQL, partitioning, federated queries, cost control)
- Kinesis (Data Streams, Firehose, shards, ordering, scaling)
- EMR (Spark/Hadoop, cluster sizing, spot usage)
- Lake Formation & data-lake governance
