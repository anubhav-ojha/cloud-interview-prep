# Storage

Object, block, and file storage on AWS — durability, performance tiers, lifecycle,
and hybrid storage patterns.

**Services covered:** S3 · EBS · EFS · FSx · Storage Gateway

## Topics

- S3 (storage classes, lifecycle, versioning, replication, security)
- EBS (volume types, snapshots, performance, encryption)
- EFS & FSx (shared file systems, throughput/performance modes)
- Storage Gateway (file/volume/tape hybrid patterns)
- Data durability, availability, and cost trade-offs
