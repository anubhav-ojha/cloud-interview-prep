# Databases

Relational, NoSQL, in-memory, and analytical data stores on AWS — picking the right
engine and operating it for scale, availability, and cost.

**Services covered:** RDS · Aurora · DynamoDB · ElastiCache · Redshift

## Topics

- RDS (engines, Multi-AZ, read replicas, backups, parameter groups)
- Aurora (storage architecture, replicas, Global Database, Serverless v2)
- DynamoDB (data modeling, partition keys, GSIs, capacity modes, streams)
- ElastiCache (Redis vs Memcached, caching patterns)
- Redshift (distribution/sort keys, RA3, Spectrum)
