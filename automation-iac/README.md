# Automation & Infrastructure as Code

Codifying and deploying AWS infrastructure — declarative provisioning, state
management, and GitOps delivery patterns.

**Tools covered:** Terraform · CloudFormation · CDK · GitOps patterns

## Topics

- Terraform (state, modules, workspaces, drift, backends)
- CloudFormation (stacks, StackSets, change sets, nested stacks)
- CDK (constructs, synthesis, testing)
- GitOps & CI/CD for infrastructure (pipelines, policy-as-code, drift detection)
- IaC comparison and when to use each
