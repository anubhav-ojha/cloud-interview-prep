# Operations & Real-World Scenarios

Running AWS in production — resilience, incident response, cost discipline, and the
open-ended scenario questions that separate Associate from Professional candidates.

**Themes covered:** Disaster Recovery · Troubleshooting · Cost Optimization · SRE

## Topics

- Disaster recovery (RPO/RTO, backup/restore, pilot light, warm standby, multi-region)
- Troubleshooting (systematic diagnosis across compute, network, and data layers)
- Cost optimization (right-sizing, Savings Plans, Spot, storage tiering, tagging)
- SRE & observability (SLOs, monitoring, alerting, on-call, chaos)
- Open-ended architecture & design scenarios
