# Compute

Provisioning and running workloads on AWS — virtual machines, containers, and
serverless functions. This domain covers when to reach for each compute model and
the operational trade-offs between them.

**Services covered:** EC2 · Lambda · ECS · EKS · Fargate

## Topics

- EC2 (instance families, pricing models, placement groups, auto scaling)
- Lambda (execution model, cold starts, concurrency, event sources)
- ECS & Fargate (task/service model, capacity providers)
- EKS (control plane, node groups, IRSA, networking)
- Choosing between EC2 / containers / serverless
